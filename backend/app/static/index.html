B.Tech (CSE/IT/ECE)
1 Problem Statement & Motivation
  • Manual WhatsApp groups & notice boards fail to track lost ID cards, wallets, and earphones.
  • No centralized digital database or automated notification.
  • Time & discovery locations are lost, making recovery rate below 25%.
2 Where is AI? (Evaluation Defense)
  • TF-IDF & Cosine Similarity Embeddings compare lost vs found textual descriptions.
  • Weighted Multi-Attribute Scoring Engine: Category (20%), Color (15%), Brand (10%), Location Proximity (10%), Temporal Window (10%), Text Semantics (35%).
3 Where is IoT? (Hardware Architecture)
  • ESP32 Microcontroller:Handles Wi-Fi HTTP API communication.
  • MFRC-522 RFID: Scans temporary RFID tags on deposited items.
  • SSD1306 OLED: Displays live feedback (“ITEM REGISTERED”).
  • SG90 Servo + Buzzer: Automated physical locking and audio chime.
4 Security & Ownership Verification
  • AI doesnot return items automatically — prevents fake claims.
  • Student submits private verification proof (e.g. wallpaper, inner contents, lock PIN).
  • Proctor verifies proof before changing item state to RESOLVED / RETURNED.
